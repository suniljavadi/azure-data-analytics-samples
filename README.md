# Azure Data and Analytics Sample

**Status: Experimental sample collection**

A small mixed portfolio repository containing a Power BI report, an HR analytics notebook, and exported Azure Data Factory configuration. It is useful as a reference snapshot, not a complete deployable data platform.

## Contents

- `Hr analytics.ipynb`: notebook-based HR analysis.
- `CaseStudy1.pbix`: Power BI report file.
- `factory/Sampleazuredatafactorysunil1.json`: exported Azure Data Factory factory configuration.
- `integrationRuntime/integrationRuntime1.json`: exported integration-runtime configuration.
- `publish_config.json`: publish-related configuration export.

## How To Explore

- Open the notebook in Jupyter or VS Code with a Python data-analysis environment.
- Open the `.pbix` file in Power BI Desktop.
- Review the JSON exports as Azure Data Factory ARM-style configuration artifacts.

There is no shared requirements file, application entry point, automated test suite, or documented deployment command in this repository. The Azure configuration should not be deployed without reviewing environment-specific names, connections, identities, and permissions.

## Skills Demonstrated

Notebook-based analytics, Power BI reporting, and exposure to Azure Data Factory configuration artifacts.

## Future Improvements

Add dataset provenance, notebook environment instructions, screenshots, a deployment parameter guide, secret/connection guidance, and a clear separation between development and production configuration.
